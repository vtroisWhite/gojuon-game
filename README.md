# 五十音学习

[开始学习](https://vtroisWhite.github.io/gojuon-game/) · [English](README.en.md)

适合电脑和手机的五十音练习游戏。自由组合平假名和片假名，按照自己的节奏学习，进度保存在当前浏览器。

## 功能与玩法

- 分行学习：每次认识 3–5 个假名，浏览学习卡后练习，可混入已浏览的单元。
- 自由练习：六类题库自由多选，支持按行筛选、正向／反向／混合与 10／20／40／全部题量；同局假名不重复。
- 到期复习：按假名和方向安排复习，优先处理待纠正和逾期内容。
- 易混辨析：练习形近假名和个人常见误选组合，答后展示辨形提示。
- 每题三个编号选项，另有“我不会”；可先回想再显示选项。答对后可手动、标准或快速继续，答错后手动继续。
- 学习、复习和辨析中的错题最多追加一次间隔巩固；无法形成间隔时留待下次复习。
- 无倒计时，切到后台自动暂停；支持简体中文和英语。

| 操作 | 快捷键 |
| --- | --- |
| 选择答案 | `1`、`2`、`3`（支持数字小键盘） |
| 我不会 | `0`（支持数字小键盘） |
| 暂停／继续 | `Space` |
| 手动进入下一题 | `Enter` |

每套包含清音 46、浊音及半浊音 25、基础拗音 33，共 208 个条目；浊拗音及半浊拗音归入拗音。

## 学习记录

主正确率、连击和近期表现只统计基础题；巩固复测单独记录纠正数。学习卡浏览不计成绩。“我不会”计为未答对，不产生混淆关系。

按假名和方向记录练习表现、最近 20 次基础作答、误选关系、全部作答平均耗时和首次答对平均耗时（ms），均值显示计时样本数。计时不含暂停、后台及反馈等待，速度趋势只比较相同练习条件。

复习间隔按表现逐步延长，默认 1／3／7／14／30 天。同日重复练习和看过答案后的纠正不会提高跨日复习等级。五十音表展示覆盖情况、熟悉程度和到期状态。

保留最近 100 局摘要，累计统计不随裁剪减少。刷新后保持题序、选项及反馈阶段，以暂停状态恢复；主动结束或替换当前局会记为未完成。

数据仅保存在当前浏览器的 `localStorage`，使用 `gojuon-game:v1`；不上传学习记录，无账号或分析追踪。清空记录需确认。存储异常可继续临时练习；开发数据结构不匹配时可清空重置。

## 读音约定

使用 `shi / chi / tsu / fu` 等常用罗马音；`じ / ぢ` 对应 `ji`，`ず / づ` 对应 `zu`。`を / ヲ` 标作 `wo`，通常读作 `o`；出题时按同音处理。基础拗音不含外来语扩展组合。

参考：[日本文化厅假名表](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kyoiku/seikatsusha/h24_nihongo_program_a/pdf/a_56.pdf)。

## 本地开发

需要 **Node.js 24** 和 npm，项目文件采用 UTF-8。

```sh
npm ci
npm run dev
```

本地检查：`npm run typecheck`、`npm test`、`npm run build`。反馈节奏、复习间隔和统计阈值统一配置在 `src/config.ts`。
